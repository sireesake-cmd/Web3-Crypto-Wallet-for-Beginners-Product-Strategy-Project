# UX Flows and User Journeys

## Overview
This document outlines the UX flows and user journeys for the Web3 Crypto Wallet for Beginners Product Strategy Project.

## User Journey 1: Setting Up the Wallet
1. **Download the App**  
   User visits the app store and downloads the crypto wallet app.
2. **Create a New Account**  
   User opens the app and selects 'Create New Account'.  
   - Input: Email, password.
3. **Verify Account**  
   User receives a verification email and clicks the link to verify.
4. **Set Up Recovery Phrase**  
   User is prompted to set and confirm a recovery phrase.  
5. **Account Dashboard**  
   User is directed to the account dashboard after setup.

## User Journey 2: Making a Transaction
1. **Open Wallet App**  
   User launches the wallet application.
2. **Select 'Send' Option**  
   User navigates to the send money option.
3. **Input Recipient Address**  
   User enters the wallet address of the recipient.
4. **Input Amount**  
   User specifies the amount to send.
5. **Confirm Transaction**  
   User reviews the transaction details before confirming.
6. **Transaction Complete**  
   User receives a notification of transaction completion.

## UX Flows
- **Account Creation Flow**  
   1. App Launch  
   2. User Selects 'Create Account'  
   3. Input Email & Password  
   4. Verification Email Sent  
   5. User Verifies Email  
   6. Set Recovery Phrase  
   7. Access Dashboard

- **Transaction Flow**  
   1. App Launch  
   2. User Selects 'Send'  
   3. Enter Recipient Address  
   4. Enter Amount  
   5. Review Transaction  
   6. Confirm

## Conclusion
This document provides a simplified view of the intended users' journey and the necessary steps to navigate through the application.
