# Success Metrics and KPIs

## Success Metrics:
1. **User Growth**  
   - Measure the number of new users acquired over time.
   
2. **User Retention**  
   - Track the percentage of users who continue using the wallet after a certain period (e.g., 30 days).

3. **Transaction Volume**  
   - Monitor the total number of transactions completed within the wallet.

4. **Customer Satisfaction (CSAT)**  
   - Gather user feedback and satisfaction scores through surveys.
   
## Key Performance Indicators (KPIs):
1. **Monthly Active Users (MAU)**  
   - The number of distinct users who interact with the wallet in a given month.
   
2. **Churn Rate**  
   - The percentage of users who stop using the wallet over a specific timeframe.
   
3. **Average Transaction Value (ATV)**  
   - The average dollar amount of transactions made through the wallet.
   
4. **Net Promoter Score (NPS)**  
   - A measure of user loyalty and likelihood to recommend the product to others.
   
5. **Feature Adoption Rate**  
   - The percentage of users who utilize newly released features within the wallet.
